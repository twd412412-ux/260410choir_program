# 행사 프로그램 악보 연결

- 띄어쓰기는 기존처럼 무시. 곡명 전체가 일치해야 하며 부분 문자열은 자동 연결하지 않음.
- 행사 프로그램에서만 제목 끝의 알려진 편곡 표기(남성합창, 여성합창, 혼성합창, 남성중창, 여성중창, 소중창, 독창, 듀엣 등)를 곡명과 분리해 비교.
- 예: `주를봐요`와 `주를 봐요(남성합창)`. 해당 편곡만 있으면 기존 파일을 그대로 자동 연결.
- 같은 곡에 일반·남성합창·여성합창 등 여러 편곡이 있으면 자동 연결 중단. 일정 상세에 버전 선택 필요 표시.
- 일정 수정 > 프로그램의 곡별 구성 > `악보 연결`에서 사용할 기존 악보 제목 선택. `연결 안 함`도 가능.
- 선택은 각 프로그램 항목의 `scoreTitle`에 저장. 같은 곡을 여러 순서에서 사용해도 각각 선택 가능.
- 가사·파일·악보 제목을 수정하거나 다른 버전으로 교체하지 않음. 선택한 제목이 삭제되거나 변경되면 임의의 다른 악보로 대체하지 않음.
- 영어 병기 등 기존 정확한 제목 매칭과 직접 연결은 유지. 알 수 없는 괄호 내용은 자동으로 제거하지 않음.
- 주일찬송 등 프로그램 없는 일정과 악보 업로드의 버전 교체 매칭은 기존 엄격한 규칙 유지.
